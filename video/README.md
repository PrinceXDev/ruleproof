# RuleProof hackathon film

A 90 second launch film and a 30 second teaser, built with [Remotion](https://www.remotion.dev/docs) (React + TypeScript).
Everything on screen comes from the real project: the Studio and workbench screenshots in `docs/media`, the logo geometry from `docs/media/logo.svg`, and the real output of `ruleproof-ci -fixture partial -bypass` (12 checks passed, 27 bypass attempts, 9 leaked). Nothing here invents a feature, a metric or a customer.

| Output | Composition | Length |
| --- | --- | --- |
| `out/ruleproof-hackathon.mp4` | `RuleProofHackathon` (with narration and the speaking presenter column) | 90 s |
| `out/ruleproof-hackathon-no-voice.mp4` | `RuleProofHackathonNoVoice` (music, sound design, on-screen story and captions only) | 90 s |
| `out/ruleproof-teaser.mp4` | `RuleProofTeaser` | 30 s |

1920 × 1080, 30 fps, H.264 + AAC.

## Run it

```sh
cd video
npm install
npm run dev                      # Remotion Studio preview
npm run render                   # renders all three MP4s into out/
node scripts/render-all.mjs main # or: novoice | teaser
```

Single compositions with the Remotion CLI:

```sh
npx remotion render RuleProofHackathon out/ruleproof-hackathon.mp4
npx remotion render RuleProofTeaser out/ruleproof-teaser.mp4
npx remotion still RuleProofHackathon out/frame.png --frame=1830
```

## Rebuild the generated assets

| Command | What it does |
| --- | --- |
| `node scripts/copy-assets.mjs <photo>` | Copies the repo media, local fonts and the presenter photo into `public/` |
| `npm run audio` | Synthesises the score and every sound effect (`public/audio/*.wav`) from `timeline.json` + `cues.json` |
| `npm run vo` | Narration clips (`public/vo/*.wav`, Windows `System.Speech`), loudness envelope, caption files and manifests |
| `node scripts/gen-captions.mjs` | `out/captions/*.srt|vtt`, `out/manifests/timing-manifest.json`, `out/manifests/asset-manifest.json` |
| `node scripts/stills.mjs <comp> <frames…>` | Review frames to `out/stills/` |

## How it is put together

- `timeline.json` holds scene start frames and the narration script. `cues.json` holds the named frame of every beat in each scene (`click`, `ok200`, `leak9` …). Scenes, sound design and captions all read the same two files, so audio and picture cannot drift apart.
- `src/components`: `CinematicScene`, `SceneTransition`, `AnimatedHeadline`, `BrowserMockup`, `TerminalRequest`, `DataFlow`, `PermissionMatrix`, `EvidenceInspector`, `StatusCounter`, `BypassReveal`, `ImpactGraph`, `LogoReveal`, `AudioTrack`, `Speaker`, `Captions`, `Cursor`, `StudioShell`.
- All motion is computed from `useCurrentFrame()` with `interpolate`, `spring` and analytic Bézier maths. There are no CSS animations or timers, so repeated renders are identical.
- Fonts (Inter, Space Grotesk, JetBrains Mono) are bundled locally; the render needs no network.
- Recreated UI (typing, permission matrix, evidence chain, pipeline) follows the real Studio layout and wording. The montage in scene 8 uses the unedited screenshots.

## The presenter

The portrait on the right edge (`public/media/speaker.webp`) is driven by the narration. `scripts/gen-vo.py` measures the loudness of every clip per frame; `Speaker` turns that into a glowing frame, voice rings and a live waveform, so it only "speaks" while there is voice. The no-voice version hides it.

To use your own voice, record each line as `public/vo/<id>.wav` (ids are in `timeline.json`), then run `python scripts/gen-vo.py --keep && node scripts/gen-captions.mjs`. Durations and the speaking animation are re-measured from your files. If a clip runs longer than its scene window, shorten the text or move its `offset`.

## Sound

All music and effects are generated by `scripts/gen-score.mjs`: no samples, no licensing. The cut at the `200 OK` and the silence before the bypass twist are explicit gates (see `out/manifests`). Music ducks under the voice in `AudioTrack`.

## Honest limits

- Narration uses the offline Windows voice (`Microsoft David Desktop`) because online neural voices were not reachable from the build machine. It is clear but plainly synthetic. A real recording dropped into `public/vo/` replaces it.
- Caption word timing is spread over each clip by word length, not forced-aligned.
- The photo does not animate a mouth; the speaking effect is audio-reactive framing around it.
- The scene 1 app UI ("Asset Workspace") is a generic illustration of a UI that blocks access; the `GET /assets/b1` request and the `{"asset":"b1","tenant":"B"}` response are the real fixture values.
- Impact analysis is shown as static analysis that sends no requests, matching the product docs.
